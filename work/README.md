# work/ — analysis output

The stage-by-stage output of the pass described in [`../README.md`](../README.md) and [`../DEOBFUSCATION.md`](../DEOBFUSCATION.md). Everything here was generated from one licensed copy of `ItemsAdder_4.0.18.jar`.

```
01-inventory/     which bytecode touches the outside world — counts and signatures
02-audit/         static scan results — counts and keyword tallies
03-deobfuscation/ the 1,674-class rename map, NMS hints, and result counters
```

**Policy for this directory: counts, signatures and derived names only.** No verbatim strings from the JAR, no decompiled source, no URL literals, no configuration values, no purchaser data. The raw scanner dumps are kept locally with the licensed copy.

## 01-inventory

`bytecode-surface-summary.md` — how many methods call `Runtime.exec`, start a `ProcessBuilder`, call `defineClass`, open a socket or HTTP connection, or match a string-decoder signature; plus the signature list for the process-execution and class-definition sites. Generated by [`../tools/ClassScan.java`](../tools/ClassScan.java), which emits one line per site; the string payloads are stripped before publishing.

## 02-audit

`scan-summary.md` — entry count, class count, how many unique URL literals and base64 candidates exist, IP and native-reference presence, high-entropy count, and a per-keyword tally. Generated by [`../tools/scan_jar.py`](../tools/scan_jar.py); the raw dump of constants stays local.

The findings that matter are written up in [`../AUDIT.md`](../AUDIT.md).

## 03-deobfuscation

`mapping.tsv` — 1,674 rows, `old`, `new`, `kind`. The complete rename map. The `evidence` column from the local run is dropped here because it quotes short literals from the JAR; the rule names alone carry the meaning.

`nms-hints.tsv` — 314 hints parsed from the NMS factory switch: obfuscated wrapper → readable name. Generated by [`../tools/hints.py`](../tools/hints.py).

`stats.md` — the numbers: rule distribution, verification counters, limits.

## What is deliberately not here

The pipeline also produces, locally:

- `src_obf/` — 1,946 decompiled classes, original names
- `src/` — 1,946 decompiled classes, renamed
- `ItemsAdder_4.0.18.deobf.jar` — the remapped JAR
- the original JAR and its extracted config, language and pack assets

Those are **not** committed. They are the copyrighted work of LoneDev, reproduced or modified. The mapping, the counters and the tools are original analysis; the source trees and JARs are not. Keep them local to your licensed copy.

## Regenerate

```bash
# 1. scan: raw output stays local
python tools/scan_jar.py path/to/ItemsAdder.jar > raw-scan.txt      # then summarize to work/02-audit/scan-summary.md

# 2. bytecode surface: signatures only
javac --add-exports java.base/jdk.internal.org.objectweb.asm=ALL-UNNAMED tools/ClassScan.java
java  --add-exports java.base/jdk.internal.org.objectweb.asm=ALL-UNNAMED ClassScan path/to/ItemsAdder.jar > raw-surface.txt

# 3. rename map
python tools/hints.py src_obf out/hints.tsv
javac -cp asm.jar tools/Deobf.java
java  -cp "asm.jar;." Deobf path/to/ItemsAdder.jar out

# 4. strip the evidence column before publishing mapping.tsv
cut -f1-3 out/mapping.tsv > work/03-deobfuscation/mapping.tsv
```
