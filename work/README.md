# work/ — analysis output

The stage-by-stage output of the pass described in [`../README.md`](../README.md) and [`../DEOBFUSCATION.md`](../DEOBFUSCATION.md). Everything here was generated from one licensed copy of `ItemsAdder_4.0.18.jar`.

```
01-inventory/     which bytecode touches the outside world — counts and signatures
02-audit/         static scan results — counts and keyword tallies
03-deobfuscation/ the 1,674-class rename map, NMS hints, fact table, counters
04-decompiled/    the decompiled source (renamed and original) and the renamed JAR
```

## 01-inventory

`bytecode-surface-summary.md` — how many methods call `Runtime.exec`, start a `ProcessBuilder`, call `defineClass`, open a socket or HTTP connection, or match a string-decoder signature; plus the signature list for the process-execution and class-definition sites. Generated by [`../tools/ClassScan.java`](../tools/ClassScan.java), which emits one line per site.

## 02-audit

`scan-summary.md` — entry count, class count, how many unique URL literals and base64 candidates exist, IP and native-reference presence, high-entropy count, and a per-keyword tally. Generated by [`../tools/scan_jar.py`](../tools/scan_jar.py).

The findings that matter are written up in [`../AUDIT.md`](../AUDIT.md).

## Regenerate

```bash
# 1. scan
python tools/scan_jar.py path/to/ItemsAdder.jar > raw-scan.txt      # then summarize to work/02-audit/scan-summary.md

# 2. bytecode surface
javac --add-exports java.base/jdk.internal.org.objectweb.asm=ALL-UNNAMED tools/ClassScan.java
java  --add-exports java.base/jdk.internal.org.objectweb.asm=ALL-UNNAMED ClassScan path/to/ItemsAdder.jar > raw-surface.txt

# 3. rename map
python tools/hints.py src_obf out/hints.tsv
javac -cp asm.jar tools/Deobf.java tools/Describe.java tools/Verify.java
java  -cp "asm.jar;." Deobf    path/to/ItemsAdder.jar out
java  -cp "asm.jar;." Describe out/ItemsAdder_4.0.18.deobf.jar out/mapping.tsv out/classes.tsv
java  -cp "asm.jar;." Verify   out/ItemsAdder_4.0.18.deobf.jar

# 4. catalogue
python tools/render_catalog.py
```
